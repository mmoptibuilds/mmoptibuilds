## Locked launch architecture

One private Git repository and one Next.js App Router application. The production deployment uses Cloudflare Workers through OpenNext, with Supabase for data and owner authentication. Cloudflare provides DNS, TLS, Turnstile, Web Analytics, and email routing. The public site has one parent gateway, two independent visual systems, and one private owner dashboard.
