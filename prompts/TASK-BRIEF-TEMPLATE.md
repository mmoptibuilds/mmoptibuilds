# Agent task brief

## Outcome

State one observable user or system outcome.

## Read first

List only the relevant project-pack documents and code paths.

## Owned files

List files this agent may edit. Everything else is read-only.

## Acceptance criteria

Use specific behavior, responsive, accessibility, security, performance, copy, and test criteria.

## Exclusions

State what must not be changed or invented.

## Model and context

Choose the least expensive capable model. Define low, medium, or high curated context. Never provide credentials, personal inquiry data, or the full interview.

## Handoff

Report inspection, changes, untouched areas, dependencies, commands, tests, failures, risks, and next action.
