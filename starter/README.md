# MMOptiBuilds dependency-only starter

This archive intentionally contains manifests, lockfile, environment names, and tool configuration—no application source and no `node_modules`.

Use Node.js 22 or newer. Run `npm ci`, then create the application from the detailed implementation plan. Do not add all visual-lab libraries at once; the allowlist in the parent pack explains when each may be installed.

Before production, review current package releases, Cloudflare compatibility, environment bindings, and every commercial-service term.
